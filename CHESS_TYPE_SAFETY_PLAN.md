## Context
The request is to make the Python chess engine/terminal agent type-safe, add executable mypy and Ruff gates, and use the latest stable Python line, 3.14. The package currently declares Python 3.10+, the CI matrix runs 3.10/3.12, and the locked dev extra contains only pytest/pytest-cov. Set the supported floor and default local/CI interpreter to 3.14, preserve chess and CLI behavior, and expose the package's inline types to consumers; this intentionally ends support for Python 3.10–3.13.
## Approach
1. In `pyproject.toml`, set `requires-python = ">=3.14"` and add `mypy>=2.3,<3` and `ruff>=0.16,<1` to the existing `dev` extra using `uv add --optional dev 'mypy>=2.3,<3' 'ruff>=0.16,<1'` after changing the Python floor; regenerate `uv.lock` for the new floor. Create `.python-version` containing `3.14` so `uv sync` and `uv run` select the 3.14 line rather than an existing 3.12 virtualenv; run `uv sync --python 3.14 --extra dev --locked` to recreate that environment. Set `[tool.mypy] python_version = "3.14"`, `files = ["chess"]`, `strict = true`; do not check `tests/` with mypy because they intentionally construct invalid public inputs. Set `[tool.ruff] target-version = "py314"`, `line-length = 88`, and `[tool.ruff.lint] select = ["E4", "E7", "E9", "F", "I"]`. Apply safe Ruff import/lint fixes and format `chess/` and `tests/`, then fix remaining diagnostics without suppressions.
2. In `chess/game.py`, add `-> Iterator[Move]` (from `collections.abc`) to `_piece_moves` and `_castling_moves`. Remove the unused `special: str = "none"` parameter from `_move_variants` and rely on `Move`'s default `special` in its non-promotion return; all two callsites pass only the existing parameters. In `chess/move.py`, declare `type MoveSpecial = Literal["none", "castle_k", "castle_q", "en_passant", "promotion"]` and annotate `Move.special: MoveSpecial` without changing its default or runtime validation. In `_castling_moves`, assign the existing rows to `castle_options: tuple[tuple[MoveSpecial, str, int, tuple[int, ...], tuple[int, ...], int], ...]` and iterate those instead of the untyped inline tuple. In `Board.from_notation`, assign the existing setup rows to `placements: tuple[tuple[Color, int, int], ...]`; in `_next_rights`, assign the existing rook rows to `home_rooks: tuple[tuple[Color, int, tuple[str, str]], ...]`. Keep all tuple contents and order. Resolve any further strict-mypy diagnostics with concrete annotations or proven narrowing, not `Any`, casts, global ignores, or changed chess semantics.
3. Create empty `chess/py.typed` and declare `[tool.setuptools.package-data] chess = ["py.typed"]` in `pyproject.toml` so editable installs and wheels advertise inline types. In `.github/workflows/tests.yml`, replace the 3.10/3.12 matrix with Python 3.14 (one job); after the locked dev install and before pytest, run `uv run --locked --extra dev ruff check chess tests`, `uv run --locked --extra dev ruff format --check chess tests`, and `uv run --locked --extra dev mypy chess`; keep coverage and wheel tests. Extend the isolated wheel smoke assertion to require `Path(chess.__file__).with_name("py.typed").is_file()`. In `README.md`, change the Python 3.10+ claims at lines 3 and 14 to Python 3.14+, and change the first-install command at line 10 to `uv sync --python 3.14 --locked`; `.python-version` also makes the unchanged `install.sh` and README play command choose 3.14. Leave the unrelated `SEARCH_OPPONENT_PLAN.md` unchanged.
